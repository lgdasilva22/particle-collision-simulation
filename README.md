# Particle Collision Simulation

## Overview

This project was developed as part of the CS330: Computational Graphics & Visualization course at Southern New Hampshire University

The goal of the project was to simulate particle movement and interactions through collision detection. As particles move around the scene, they respond to collisions and change direction, creating a real-time visual simulation

## Technologies Used
- C++
- OpenGL
- GLFW

## Skills Demonstrated
- Collision Detection
- Real-Time Simulation
- Lighting & Materials
- Object-Oriented Programming (OOP)
- OpenGL Development
- Problem Solving
- Debugging

## What I Learned

Working on this project helped me better understand collision detection, object movement, and simulation logic. It also strengthened my ability to debug complex interactions between multiple objects and manage real-time program behavior.

I also improved my understanding of how OpenGL and GLFW can be used to render real-time applications and visual simulations
